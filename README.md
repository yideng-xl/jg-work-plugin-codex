# jg-work-plugin-codex

JG 工作类 Codex 插件。

当前包含 `reimburse` Skill，用于整理差旅、订阅和其他报销材料：

- 扫描并核对发票；
- 生成报销摘要和 OA 明细；
- 待确认摘要使用 `05-需确认-`，确认后的 Excel、PDF 使用 `09-终稿-`；
- 订阅类报销事由按原始币种列明金额构成；
- 订阅类费用发生日期使用实际 AI 订阅时间；
- 按普票、专票拆分 A4 打印 PDF；
- 普票 PDF 打印 1 次；专票 PDF 内每张发票只放一次，整份打印 2 次；
- 美元费用优先按实际扣款或同期票据确定汇率。

## 报销流程

报销分为“差旅”和“通用”两类。两类都必须先生成中间确认表，用户确认后才能生成终稿。

```text
整理原始票据
    ↓
判断：差旅 / 通用
    ↓
扫描票据并核对金额、税额、费用分类
    ↓
生成 05-需确认-报销摘要.xlsx
    ↓
用户检查并确认
    ↓
生成 09-终稿-*.xlsx / 09-终稿-*.pdf
```

### 1. 整理原始票据

为本次报销新建一个文件夹，将相关材料放入该文件夹。原始材料包括发票 PDF/XML、行程单、住宿水单、订阅回执和支付凭证等。

推荐目录：

```text
90-invoice/
├── 01-出差/
│   └── 2026-07-20/
└── 10-AI订阅/
    └── 202607/
```

原始票据保留原文件名。插件生成的文件会直接放在本次报销目录中。

### 2. 选择报销类型

- **差旅**：跨城市出行，可能包含火车、飞机、住宿、出差期间打车和补贴。终稿包含 OA 差旅明细；有打车时还会生成交通费明细。
- **通用**：AI 订阅、市内交通、办公费用等不需要填写差旅行程的报销。终稿使用 OA 通用报销明细。

开始时需要明确告诉 Codex：“这是差旅报销”或“这是通用报销”，并给出本次报销文件夹和报销人姓名。没有提供姓名时，Codex 必须先询问“本次报销人是谁？”，拿到明确姓名后再处理票据。

### 3. 生成并确认中间表

Codex 扫描原始材料，核对金额、税额、票种和费用分类，先生成：

```text
05-需确认-报销摘要.xlsx
```

这份表是中间确认表，不是终稿。用户需要检查标黄内容、日期、金额、费用分类、起止地和报销事由，并确认本次实际报销人。报销人不能固定成历史使用者的姓名。修改完成后，明确回复“确认，可以生成终稿”。

### 4. 生成终稿

Codex 读回已经确认的摘要，再生成以 `09-终稿-` 开头的文件：

- `09-终稿-OA差旅报销明细.xlsx` 或 `09-终稿-OA报销金额明细.xlsx`
- `09-终稿-交通费明细.xlsx`，仅差旅且存在打车时生成
- `09-终稿-A4发票-普票-打印1张.pdf`
- `09-终稿-A4发票-专票-整份打印2次.pdf`

普票和专票分开。每张发票在 PDF 中只放一次；专票文件由用户整份打印两次。某类没有发票时，不生成对应的空 PDF。

### 5. 最终检查

交付前核对：

- 终稿金额与确认后的摘要一致；
- 预充值发票没有计入报销；
- 普票和专票没有混在同一个 PDF；
- 文件名符合 `05-需确认-` / `09-终稿-` 规则；
- AI 订阅日期和金额构成使用实际订阅凭证。

## 后续规划：Chrome 插件自动填报

后续计划开发 Chrome 插件，读取已经确认的 OA 终稿 Excel，自动填入 OA 报销页面。

规划流程：

```text
选择 09-终稿-OA*.xlsx
    ↓
识别通用 / 差旅表格
    ↓
解析表头、费用明细和差旅行程
    ↓
识别当前 OA 页面及字段
    ↓
展示填报预览和异常提示
    ↓
用户确认后自动填入
    ↓
用户检查并手动提交
```

第一阶段范围：

- 只读取 `09-终稿-OA报销金额明细.xlsx` 和 `09-终稿-OA差旅报销明细.xlsx`；
- 支持通用报销和差旅报销两类 OA 表单；
- 自动填写表头、报销事由、费用明细和差旅行程；
- 填写前展示字段映射、金额合计和缺失项；
- 页面结构变化或字段无法匹配时停止填写并提示；
- 不保存 OA 账号、密码或票据内容；
- 不自动点击提交，由用户检查后手动提交。

实施顺序：

1. 整理两类终稿 Excel 与 OA 页面字段的映射表。
2. 完成本地 Excel 解析和通用/差旅类型识别。
3. 完成 OA 页面识别、字段定位和多行明细填写。
4. 增加填报前预览、金额校验和异常提示。
5. 用真实报销样本验证，再决定是否扩展附件上传等能力。

## 安装

```bash
codex plugin marketplace add yideng-xl/jg-work-plugin-codex --ref main
```

重启 Codex 后，在 **Plugins** 中找到 **JG Work**，安装 `jg-work-plugin-codex`。

## 更新

```bash
codex plugin marketplace upgrade jg-work
```

更新后重启 Codex，并新建任务使用。
