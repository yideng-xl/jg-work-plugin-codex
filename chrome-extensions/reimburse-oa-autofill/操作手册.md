# OA 报销自动填写插件操作手册

## 1. 用途

插件读取已确认的 OA 报销终稿 Excel，将内容填入 OA“处理 - 技术报销”页面。

支持两类文件：

- 差旅：`09-终稿-OA差旅报销明细.xlsx`
- 其他报销：`09-终稿-OA报销金额明细.xlsx`

插件只填写页面。附件、检查、保存和提交由用户手动完成。

## 2. 安装

1. 解压插件安装包，保留解压后的完整目录。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的插件目录。该目录中应能直接看到 `manifest.json`。
6. 在 Chrome 工具栏固定“OA 报销自动填写”。

更新插件时，解压新版并覆盖旧目录，再到扩展程序页点击“重新加载”。

## 3. 使用前检查

开始前确认：

- 已登录 OA。
- 已进入“处理 - 技术报销”的完整表单页面。
- OA 报销类型与 Excel 一致。
- Excel 文件名以 `09-终稿-OA` 开头。
- Excel 已经人工确认，金额和费用分类无误。

插件不支持 OA“创建 - 技术报销”页面。

## 4. 填写步骤

1. 点击 Chrome 工具栏中的插件图标。
2. 点击“选择文件”，选择对应的终稿 Excel。
3. 检查文件预览中的报销类型、申请人、行程数、费用行数和金额。
4. 如果 OA 明细已有数据，分别处理“行程明细”和“费用明细”：
   - **覆盖**：清除该表已有数据，再按 Excel 填写。
   - **只新增**：保留已有数据，在后面增加 Excel 明细。
   - **取消**：本次不填写该表。
5. 点击“填入 OA”。
6. 等待完成提示，不要在填写过程中操作 OA 页面。
7. 回到 OA 页面逐项检查。

行程明细和费用明细分别判断，互不影响。

## 5. 差旅报销规则

差旅报销会填写：

- 出差天数、实际工作天数等可编辑表头字段。
- 出发日期、出发时间、出发地、到达日期、到达时间、目的地、住宿天数。
- 费用分类、行程编号、报销金额、增值税专票税额。
- 出差申请记录。

插件根据第 1 段行程的出发日期，选择出发日期之前最近的一条出差申请记录。同日申请不选。

如果最近日期有多条记录，或没有符合条件的记录，插件保留为空，由用户手动选择。

OA 选择出差申请记录后可能自动生成第 1 行行程。插件会复用该行，再按 Excel 补足剩余行程，不会删除这条关联行。

填写完成后，提示框会显示所选出差申请记录的申请日期。用户必须检查记录是否正确。

## 6. 其他报销规则

其他报销只填写费用明细，不填写行程和出差申请记录。

费用明细包含：

- 费用分类。
- 费用发生日期。
- 报销金额。
- 增值税专票税额。

## 7. 填写后检查

提交前至少检查以下内容：

- 申请人和报销类型正确。
- 差旅报销的出差申请记录正确。
- 行程数量、日期、时间、地点和住宿天数正确。
- 费用分类和行程编号正确。
- 费用合计、税额合计、报销总金额与 Excel 一致。
- 所需附件已经手动上传。

确认无误后，再由用户手动保存或提交。

## 8. 常见提示

### 当前页面不支持填写

确认当前页面是“处理 - 技术报销”的完整表单。返回列表页或创建页都无法填写。

### Excel 报销类型与 OA 页面不一致

检查 OA 的“报销类型”，并重新选择同类型的终稿 Excel。

### 搜索结果为 0 或存在多条完全一致结果

插件会停止填写，避免选错费用分类或出差申请记录。请先在 OA 中核对可选项。

### Excel 与 OA 合计不一致

检查费用明细是否全部填写，金额、税额和费用分类是否正确。修正后重新导入。

### 插件没有响应或提示连接失败

1. 到 `chrome://extensions/` 重新加载插件。
2. 刷新 OA 页面。
3. 重新打开插件并选择 Excel。

## 9. 数据和权限

- Excel 在当前浏览器页面中读取，不上传到外部服务。
- 插件不保存 OA 账号、密码或票据内容。
- 插件只在指定 OA 报销页面运行。
- 插件不会自动上传附件、保存或提交报销单。
