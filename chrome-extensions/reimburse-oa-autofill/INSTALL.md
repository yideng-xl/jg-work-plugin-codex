# OA 报销自动填写插件安装说明

## 安装

1. 解压安装包，保留解压后的完整目录。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择刚解压的插件目录。该目录中应能直接看到 `manifest.json`。
6. 将“OA 报销自动填写”固定到 Chrome 工具栏。

## 使用

1. 登录 OA，打开“处理 - 技术报销”页面。
2. 点击插件图标。
3. 选择 `09-终稿-OA差旅报销明细.xlsx` 或 `09-终稿-OA报销金额明细.xlsx`。
4. 确认预览信息后点击“填入 OA”。
5. 检查出差申请记录、行程、费用明细和合计金额。
6. 附件、保存和提交由用户手动完成。

插件更新后，重新解压覆盖原目录，再到 `chrome://extensions/` 点击插件卡片上的“重新加载”。

完整操作手册：<https://yideng-xl.github.io/jg-work-plugin-codex/>
