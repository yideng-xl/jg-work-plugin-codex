# OA 报销自动填写 Chrome 插件

读取报销 Skill 生成的终稿 Excel，填入 OA“处理 - 技术报销”完整表单。支持差旅和通用报销。

插件只填写页面。附件由用户手动上传，报销单由用户检查后手动提交。

## 支持的文件

- `09-终稿-OA差旅报销明细.xlsx`
- `09-终稿-OA报销金额明细.xlsx`

`09-终稿-交通费明细.xlsx`、发票 PDF 和其他 Excel 不在读取范围内。

## 构建

需要 Node.js 和 npm。

```bash
cd chrome-extensions/reimburse-oa-autofill
npm install
npm run check
```

构建结果在 `dist/` 目录。

## 安装到 Chrome

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `chrome-extensions/reimburse-oa-autofill/dist` 目录。
5. 每次重新构建后，在扩展程序页点击该插件的“重新加载”。

## 使用

1. 在 OA 打开已生成报销单号的“处理 - 技术报销”页面。
2. 点击 Chrome 工具栏中的插件图标。
3. 选择对应的 `09-终稿-OA*.xlsx`。
4. 检查文件类型、OA 报销人、明细行数和金额。
5. 如果 OA 的行程或费用明细已有数据，两张表分别选择“覆盖”“只新增”或“取消”。
6. 点击“填入 OA”。
7. 在 OA 中检查字段、明细和合计，手动上传附件并提交。

插件不填写或比较 OA 已有表头信息。差旅/通用文件类型与当前页面不一致，或金额不一致时，插件停止并显示原因。

差旅报销先按当前 OA 报销人过滤候选记录，再按第 1 段出发日期选择严格早于该日期且最近的一条。同日记录不选；同一报销人的最近日期有多条或没有符合记录时保留为空，由用户手动选择。填写完成后插件分行展示申请记录编号、申请日期和申请人，并从所选申请读取计划出差行程明细。每条计划行程独占一行，依次标为“行程1、行程2……”，包含出发日期、出发地、目的地、回程日期和事由。

## 当前边界

- 只支持 OA 完整的“处理 - 技术报销”页面。
- OA“创建 - 技术报销”页面还没有接入。
- 搜索选项必须存在唯一的完全一致结果。
- OA 页面结构变化后，需要重新核对字段和明细表选择器。
